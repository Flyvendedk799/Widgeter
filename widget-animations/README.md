# ✨ Widgeter Showcase — 77 Purposeful Widgets & 36 Modular Blocks

A comprehensive, ultra-high-fidelity showcase of **77 purposeful desktop widgets** and **36 modular restyling blocks** built with pure CSS & vanilla JavaScript, featuring 60 FPS Canvas renderers, real-time math models, glassmorphic styling, and desktop widget physics.

Designed specifically as a frontend visual reference and inspiration library for **[Flyvendedk799/Widgeter](https://github.com/Flyvendedk799/Widgeter)**.

- **Interactive Code Inspector**: Click `</>` on any widget to view and copy the clean HTML, CSS, or JS ready to drop directly into Widgeter's `.widget` format.
- **Instant Search Across 77 Widgets**: Type `quantum`, `tesseract`, `radar`, `nixie`, `cryo`, `doppler` to filter instantly.
- **Category Filter Pills**: Quick-filter by 10 distinct categories.
- **⚡ Simulate Spike Button**: Triggers live surges across CPU, crypto prices, audio spectrum, and network throughput.
- **Live Ticker Toggle**: Pause and resume simulated real-time data feeds anytime.
- **Compact & Normal View Modes**: Switch between standard and compact grid density.
